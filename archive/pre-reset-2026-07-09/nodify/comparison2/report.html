One-line finding. On a harder, fairer, five-topic test with a capable model, the logic tree is not a meaningful article-quality lever over disciplined thinking. The discipline is the lever; the tree ties it on quality (+0.20 vs raw, ±0 vs skills). The tree's defensible value is structural — enforced auditability, guaranteed recoverability, and a small consistent calibration edge — not better prose.

The hypothesis, and the verdict

The whole point of this run was to test the claim I'd made after v1: that the tree would help more with a weaker model on harder tasks, where an agent can't hold the reasoning in its head. Three conditions, isolated single-context runs, the only variable is the framework: raw (no method), skills (thinking discipline, no tooling), tree (full nd CLI + skill).

not supported “A weaker model needs the tree more.” The judged gap got smaller (0.20) than the Opus run (2.0), not larger — Sonnet 5 was strong enough that the floor the tree provides rarely bound.
supported The tree's edge lives in disciplined-reasoning dimensions (calibration, adversarial rigor) and in structural guarantees (auditability, recoverability) — not in evidence breadth or prose quality.

Cold-resume — keep the sources, lose the thinking

The test

Each investigation was “interrupted.” A fresh Opus agent had to rebuild the reasoning state from disk-only artifacts — tree via nd brief, skills via log.md, raw via sources/ — without reading the finished article.

Recoverability (mean, /5)

tree 5.0 · skills 5.0 · raw 3.0

raw keeps its sources but loses leanings + next-action.

Structured persistence — a disciplined log or the tree — fully preserves the investigation; raw preserves evidence but not reasoning. Tree ties skills because Sonnet wrote good logs: the tree's advantage here is enforcement, not magnitude — nd brief is guaranteed, whereas a log's quality is author-dependent (it was an empty placeholder in v1).

What I'd fix before believing more

  • Confound, disclosed: the raw prompt still asked for a counterpoints section + calibration — so “raw” here is a competent baseline, not zero-method. That inflates the low end (4.53 vs v1's 3.0) and compresses the gap.
  • Test a genuinely weak model. Sonnet 5 is “weaker than Opus,” not weak. The hypothesis needs Haiku to see if the floor binds.
  • Count studies, not DOC entries, so tree bundling stops undercounting sources.

The honest answer

The rigorous version of the experiment weakened the easy story. The tree is a floor on rigor and a guarantee of auditability + recoverability — not a quality multiplier for a good agent having a good day. It reliably matches-or-beats the unstructured baseline and never loses to it; it does not beat a disciplined agent on judged quality. Where it earns its keep is exactly where discipline-alone degrades: at scale, under real compaction, with genuinely weak models, or when the output must be audited rather than just read. On a clean single pass by a capable model, those benefits are close to free-and-invisible — which is why the gap is 0.20, not 2.0.
